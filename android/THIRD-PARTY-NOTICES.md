# Android advertising host list

`app/src/main/assets/ad-hosts.txt` is Peter Lowe's ad/tracking server list,
downloaded 19 November 2026. The upstream header and attribution are retained.
It contains 3,568 entries, last updated upstream 18 November 2026.

Author: Peter Lowe, pgl@yoyo.org.

Source: https://pgl.yoyo.org/adservers/

Download: https://pgl.yoyo.org/adservers/serverlist.php?hostformat=hosts&showintro=1&mimetype=plaintext

The publisher permits combining and redistributing the list on the source page:
“Feel free to combine this list with yours or lists from other sites and put it up on the web, though!”

This is an offline snapshot. No remote rules are downloaded at app startup.
